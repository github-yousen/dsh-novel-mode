# novel-constitution

## 用户输入

```text
$ARGUMENTS
```

执行前必须考虑用户输入（如非空）。如果用户已在输入中提供了详细设定 → 跳过引导步骤，直接使用用户提供的内容。

## 目标

创建或更新 `novel/constitution/` 目录下的设定文件，这是整部小说的"不可变设定集合"。

## 宪法目录结构

```
novel/
├── bookinfo.md              ← 书名 + 简介 + 类型（发布用元信息）
├── outline.md               ← 大纲 + 头部「创作约束」（审核红线、避毒指南）
├── constitution/
│   ├── core.md              ← 核心世界观规则 + 机器校验正则（必加载，≤5000字）
│   ├── style.md             ← 写作风格设定（≤200字，必加载）
│   ├── characters/          ← 每角色一个文件（按需加载）
│   │   ├── 林渊.md
│   │   └── ...
```

🔴 **设计原则**：core.md ≤ 5000字 + style.md ≤ 200字。审核红线放入 `outline.md` 头部「创作约束」段。角色文件按出场需求精准加载。

## 执行步骤

### 1. 初始化检查

- 检查 `novel/constitution/core.md` 是否已存在
  - 存在 → 询问用户：**修改现有宪法** / **重新创建**
  - 不存在 → 进入步骤2

### 2. 选择创建模式

```
请选择宪法创建方式：
A) 引导创建 — 我来提问，你选择/填写（推荐新手）
B) 自由输入 — 你直接提供所有设定，我来结构化
C) 文档导入 — 从已有设定文档自动提取
D) 🔥 热榜选题 — 自动查看番茄新书热榜，分析题材走向，推荐仿写方向（推荐）
```

如用户输入中已包含设定内容 → 自动进入模式B。
如用户输入中包含文件路径 → 自动进入模式C。
如用户输入中包含"热榜"/"排行"/"选题"/"番茄" → 自动进入模式D。

### 模式D：热榜选题（番茄新书排行榜分析）

🔴 **自动查看番茄小说新书热榜各分类 → 分析题材走向 → 推荐仿写方向 → 选定参考书 → 一键进入拆书流程**

#### Step D1: 抓取新书排行榜

执行脚本获取最新榜单数据：

```bash
python3 .dsh/scripts/fanqie-rank.py --gender male --top 10 --output novel/source/rank-data.json --format json
```

🔴 URL格式已验证：`/rank/{gender}_1_{catid}` = 新书榜，`/rank/{gender}_2_{catid}` = 阅读榜
🔴 gender: `1`=男频, `0`=女频

解析脚本输出，按分类展示 TOP10 榜单：
```
━━━ 📊 番茄小说男频新书排行榜（实时数据）━━━

📚 【东方仙侠】TOP5
  1. 《xxx》 xxx  [连载] 📖47.9万 📝28.8万字
  2. ...

📚 【传统玄幻】TOP5
  ...

（共展示 X 个分类的新书热榜）
```

🔴 输出字段说明：
- `📖` = 阅读数（万次），数字越大越热门
- `📝` = 字数，反映作品更新量

#### Step D2: 题材走向分析

基于榜单数据，AI 自动分析当前各题材的**爆款公式和热度信号**：

🔴 分析前必须先统计各题材热度（从 rank-data.json 中计算）：
- **均阅读数** = 该题材 TOP10 书籍的 `read_count` 均值 → 最直接的热度指标
- **头部集中度** = 第1名 `read_count` ÷ 均阅读数 → 反映竞争格局
  - < 2.0 = 竞争分散，新书容易出头 ✅
  - 2.0~3.0 = 适中
  - \> 3.0 = 头部垄断，新书难出头 ⚠️
- **饱和度** = 书名关键词重复度（同一梗出现≥3次说明饱和）

```
━━━ 🔥 题材走向分析（按均阅读数降序）━━━

| 题材 | 均阅读数 | 头部集中度 | 热度 | 当前爆款公式 | 书名关键词规律 | 推荐入场 |
|------|---------|-----------|------|-------------|---------------|---------|
| 都市脑洞 | 30.5万 | 2.1x | ⭐⭐⭐⭐⭐ | 直播曝光+科技神豪 | 妹妹/直播/曝光 | ✅ |
| 都市高武 | 28.5万 | 2.2x | ⭐⭐⭐⭐⭐ | 重生成物+国家队 | 重生/妹妹/上交国家 | ✅ |
| 玄幻脑洞 | 28.1万 | 3.4x | ⭐⭐⭐⭐⭐ | 签到+冷宫护卫 | 签到/冷宫/开局 | ⚠️头部垄断 |
| ...   |         |           |      |             |               |         |

🎯 推荐仿写方向（均阅读数高 + 头部集中度低 = 最佳入场时机）:
1. [推荐题材A] 均阅读数XX万，集中度X.Xx — 原因/当前空白点
2. [推荐题材B] 均阅读数XX万，集中度X.Xx — 原因/当前空白点
3. [推荐题材C] 均阅读数XX万，集中度X.Xx — 原因/当前空白点
```

🔴 分析维度：
- **均阅读数**：各题材 TOP10 阅读数均值，最直观反映题材热度（主指标）
- **头部集中度**：第1名÷均值，<2=分散好入场，>3=垄断难出头（竞争指标）
- 同一作者是否霸榜多位（说明作者套路成熟可拆）
- 书名关键词聚类（发现当下热门梗/套路）
- 简介中的核心卖点提取
- 题材饱和度（同一关键词出现≥3次 = 竞争激烈）

🔴 **`rank_diff`（排名变化）字段不用于题材分析**——它只反映单本书在本题材榜内的位置洗牌，与题材整体冷热无关，且实测大多数为0。

### 模式A：引导创建（分步选项式）

#### Step 0: 书名与简介

```
先确定小说的书名和简介：

【书名】（≤15字）:
- 要求：简洁有力，有记忆点，能体现核心卖点
- 公式参考：核心卖点 + 情绪钩子 + 差异化标识
- 类型参考：
  · 悬念型（矛盾冲突）："当医生开了外挂"
  · 标签型（精准定位）："全职高手"
  · 符号型（记忆锚点）："斗破苍穹"
  · 新媒体向（超长悬念）："被退婚后我成了帝国太子妃"

【简介】（150~300字）:
- 结构模板（三幕式）：
  1. Hook（钩子）：非常态事件/主角身份 + 核心设定，一句话抓住读者
  2. Stakes（赌注）：主要阻碍 + 关键抉择 + 严重后果
  3. Payoff（期待值）：暗示爽点/成长方向，留下悬念不剧透结局
- 要求：
  · 第一句话必须有吸引力（穿越/重生/觉醒/开挂等钩子）
  · 要有具体冲突和阻碍，不要只有背景介绍
  · 结尾留悬念，不要讲完整个故事
  · 语言要接地气，符合网文读者阅读习惯
  · 可以用配角的反应/金句增加画面感

请提供书名和简介，或回复"帮我想"让我根据后续设定自动生成。
```

🔴 如果用户选择"帮我想"，则在所有设定完成后（Step 5 之前）自动生成书名和简介。
🔴 书名确定后不可轻易修改（平台签约后不可改名）。

#### Step 1: 小说类型

```
你的小说属于哪种类型？

A) 玄幻修仙    B) 都市现代    C) 科幻未来
D) 古代历史    E) 悬疑推理    F) 奇幻冒险
G) 末日废土    H) 校园青春    I) 其他（请描述）
```

🔴 **新人题材避坑指南**（起点编辑星河）：
> 别问"我想写什么"，问"现在读者想看什么"。

- 🥇 **不建议新人碰的修罗场**：玄幻、仙侠（大神扎堆，签约难出头）
- 🥈 **受众固化的老赛道**：传统西幻、高武（流量向头部集中，新人难获推荐）
- 🥉 **太小众的题材**：写了没人看，数据会打击信心
- ✅ **推荐新人赛道**：末日小说、文娱题材（门槛低、粘性高）；跟平台扶持走（灵异、都市等）；找还没饱和的切入点

🔴 用户选择后，Agent 加载对应的**类型预设模板**（见下方预设库），作为后续步骤的默认值。如用户选择了不建议的赛道，Agent 应温和提醒但尊重用户最终选择。

#### Step 2: 世界观设定

基于类型预设，展示预填内容让用户**确认/修改/补充**：

```
基于「玄幻修仙」类型，以下是预设世界观（直接回复修改项，或回复"确认"通过）：

1. 时代背景: 架空仙侠世界，宗门林立
2. 力量体系: 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 大乘 → 渡劫
3. 核心规则:
   - [不可变] 突破需要天材地宝+闭关感悟
   - [不可变] 寿命随境界提升（筑基200年，金丹500年...）
4. 地理设定: （请补充你的世界地名/地理）

需要修改哪些？直接说编号，或回复"确认"。
```

🔴 每个类型都有合理的预设，用户可以一路"确认"快速通过，也可以精细调整。

#### Step 3: 角色创建

```
先创建主角。请选择或自定义：

【姓名】: （请输入）

【性格模板】选一个作为基底，之后可微调：
A) 沉默寡言型 — 话少、行动派、内心戏丰富
B) 热血冲动型 — 重情义、易怒、正义感强
C) 腹黑谋略型 — 表面温和、心思缜密、喜欢布局
D) 玩世不恭型 — 嘴贱但靠谱、幽默、关键时刻认真
E) 冷酷无情型 — 目标导向、不择手段、偶有柔软面
F) 自定义（请描述）

【说话风格】:
A) 短句冷峻 — 句子短、少修饰、不解释，但**不等于电报体**（仍要满足全章均句长目标）
B) 话痨幽默 — 话多、爱调侃、常跑题插话
C) 文雅书卷 — 用词书面、爱引经据典、语气客气
D) 粗犷直白 — 用词粗、直来直去、不耐烦
E) 自定义（请描述用词习惯与句子长短倾向，**不要给例句**）

🔴 **不要给示例台词**：示例会被后续写作阶段当成"标准句式"照抄，导致所有角色说话变成同一副腔调。
🔴 **"说话风格"约束的是用词与口癖，不是句长**：任何风格下，一句台词都可以承载完整信息（20~40 字）。
   台词过短（如三字一句连发）属于"电报体"，会被 `validate-chapter.ps1` 检测 5.5 判为段落节奏问题。

【初始位置】: （请输入，如"青云宗外门"/"临海市第一中学"）
```

每创建完一个角色，询问：
```
主角创建完成。还要添加角色吗？
A) 添加一个重要配角
B) 添加一个反派
C) 暂时够了，后续通过 /novel-constitution 补充
```

#### Step 4: 写作风格

```
最后确定写作风格：

【叙事人称】:
A) 第一人称 — "我走进山门，眼前的景象让我震惊"
B) 第三人称限制视角 — "林渊走进山门，眼前的景象让他震惊"（只知道主角想法）
C) 第三人称全知 — 可以展示所有角色的内心（适合群像）

【语言基调】:
A) 冷峻克制 — 白描为主，少用形容词，情感内敛
B) 幽默轻快 — 吐槽多，节奏明快，适合轻松向
C) 沉郁厚重 — 大量心理描写，文学感强
D) 热血燃向 — 战斗爽快，情绪外放，适合爽文
E) 自定义（请描述）

【对话格式】:
🔴 统一使用中文双引号 "" 包裹对话（唯一合法格式），如："你好。"
禁止使用：「」、『』、[]、【】、英文引号""等其他符号

```

#### Step 4.5: 文笔约束（AI 自动推导）

🔴 **用户选完基调后，AI 根据所选基调 + 类型自动推导文笔约束**，展示给用户确认：

```
根据你选择的 [冷峻克制] 基调，我为你推导了以下文笔约束：

【句式节奏】: 全章以中长句为主体（🎯 均句长 25~35 字，人类成书实测 21~33），句子须承载"动作+细节+因果"；战斗/危机段落改用短句密集提速（🔴 短句是**节奏工具**，不是默认句式；全章 ≤12 字的句子占比控制在 25% 以内）
【描写偏好】: 白描型，动作描写写实少修饰；心理描写靠行为暗示不用大段独白；环境描写点到为止用意象带过
【对话风格】: 对话按角色区分用词与口癖，单句该长就长、需较劲时可用长句；用动作tag替代"说"字；避免连续三轮以上"短问短答"
【情绪渲染】: 克制不直说，用行为+环境间接传达情绪；高潮时用细节慢镜头放大
【语言调性】: 冷硬克制，搞笑靠反差不靠段子，正式场合语言微偏文言

满意？回复"确认"或修改具体项。
回复"跳过"则不设文笔约束，由 AI 自由发挥。
```

🔴 **各基调的默认推导参考**（AI 据此生成，可微调）：

| 基调 | 句式节奏 | 描写偏好 | 对话风格 | 情绪渲染 | 语言调性 |
|:-----|:---------|:---------|:---------|:---------|:---------|
| 冷峻克制 | 中长句为主，战斗段短句密集提速 | 白描，少形容词，心理靠行为暗示 | 对话按角色区分，动作tag | 克制，行为+环境间接传达 | 冷硬，正式场合微文言 |
| 幽默轻快 | 中长句为主，节奏明快，短句用于吐槽爆点 | 夸张描写多，善用比喻制造喜感 | 对话密度高，话痨型，吐槽多 | 情绪外放，靠吐槽和反差 | 口语化强，网文梗可用 |
| 沉郁厚重 | 长句为主，复合句嵌套，节奏舒缓 | 心理描写大量，环境描写浓墨重彩 | 对话克制，每句话有潜台词 | 直面情绪，抒情段落多 | 书面语重，偏文学化 |
| 热血燃向 | 战斗段短句连击，日常段中长句 | 动作描写夸张特效型，环境为战斗服务 | 对话热血，台词有记忆点 | 情绪外放，渲染浓烈 | 偏口语，燃向台词可中二 |

🔴 **全基调共用硬约束（上表任何一行都不得违反）**：
- 全章**均句长 ≥25 字**（目标 25~35）；**≤12 字的短句占比 ≤25%**
- **基调只改变"用词与长短句配比"，不改变句长下限**——"冷峻克制"不等于电报体，"短句"是节奏工具而非默认句式
- 单段**不超过 60 字**（避免"一逗到底"）
- ⚠️ 依据：4 本专业成书各 30 万字实测，均句长 21~33 字、<12 字段落占比仅 1.6~17.9%

🔴 用户选"自定义"基调时，AI 根据用户描述自主推导，不使用上表。

#### Step 4.7: 平台审核红线确认

🔴 **此步骤必须执行**，确保作品从源头规避审核风险。

```
以下是网文平台审核规则（番茄/起点/晋江等通用），分三级：

【死线 — 绝对不碰，触犯即下架】
1. 中国现实政治人物真名、现任领导人、真实政府机构全称
2. 明确政治隐喻（谐音/缩写指代真实政治事件）
3. 侮辱丑化英雄烈士
4. 宣扬恐怖主义、极端主义、分裂主义
5. 宣扬邪教
6. 露骨色情描写（具体性行为过程、器官描写）
7. 抄袭（连续6字以上相同即判定）

【黄线 — 可以涉及，但需技巧处理】
8. 涉政：外国政治可架空化（虚构国名）；中国政治尽量回避；军队/政府用虚构番号
9. 涉黄：情感氛围、暧昧暗示可以写（"房门关上""烛火摇曳"），不写具体过程和身体细节
10. 涉暴：战斗打斗应该精彩有张力，但不详写虐杀过程/器官损毁；可写结果不写慢镜头折磨
11. 真实地名：外国地名可正常用，中国敏感地区用虚构名；不用Z国/T岛等变体指代
12. 犯罪：可有犯罪情节推动剧情，但不详写可模仿的具体手法步骤
13. 封建迷信：修仙/玄幻体系不受限；但不写"现实拜神灵验"等暗示迷信有效的内容

【弹性区 — 适度即可】
14. 民族/地域：角色可有地域特色，但不能有歧视性言论
15. 未成年人：校园文可写青春恋爱，不写未成年性行为/酗酒/吸毒的正面描写
16. 赌博/毒品：可作为剧情元素（反派贩毒），不详写制作过程，不美化
17. 自杀/自残：可作为剧情转折，不详写具体方式，侧重后果和救助
18. 暴力尺度：战斗鼓励写得精彩，控制在"热血燃"而非"血腥恶心"

【格式规范 — 影响推荐】
19. 段落不超过35字（手机端阅读）→ 已由分段脚本自动处理
20. 引用内容不超过50字，须注明出处
21. 不引用其他平台签约作品的角色/设定

以上将写入 outline.md 头部的「创作约束」段。
🔴 注意：这里写入的是**创作约束**，**不会替代** `core.md` 中的 `[不可变]` 世界观硬设定；两套规则后续会分别校验。
如有特殊需求（如写历史架空需要真实朝代名），请说明，我标注豁免项。
回复"确认"继续，或说明需要调整的项。
```

#### 自我QA与澄清：读者视角追问（Agent 必须在此步骤执行）

展示总览后，Agent **必须站在读者角度，像一个真实读者阅读设定后会产生疑问那样，对设定提出追问**。不得用清单式检查，不得跳过。

**追问方式**：Agent 模拟一个挑剔但有经验的网文读者，读到这个设定时脑子里冒出来的问题。每个问题必须是读者真的会问的，不是走过场。

**问题分级**：

- **💀 致命漏洞** — 读者第一反应就觉得不合理，不改会直接弃书
  > 例："主角被逐出家族，功法为什么没被废？家族不怕他报复？"
  > 例："这个禁地既然有进无出，那前人是怎么把情报传出来的？"

- **❓ 合理质疑** — 读者能接受但希望在后续看到解释
  > 例："金手指为什么偏偏选中主角？前任持有者去哪了？"
  > 例："反派都知道主角有系统了，为什么不用更聪明的手段？"

- **🔥 好奇追问** — 读者感兴趣但可以留悬念的问题，无需立即回答
  > 例："这个神秘老者的真实身份是什么？"
  > 例："主角的身世到底有什么秘密？"

**追问规则**：
- 用读者的口吻提问，像评论区里长的评论，不是检查报告
- 致命漏洞**必须逐条得到用户的合理解释或设定修正**，否则不通过
- 合理质疑向用户提出，用户可解释也可说"后续会写"
- 好奇追问仅列出，用户无需回应
- 用户解释后，Agent 根据新信息继续追问一轮（最多两轮），站在读者角度检查解释是否自洽

**输出格式**：
```
=== 读者视角追问 ===

读完你的设定，作为一个网文读者，我有这些疑问：

💀 致命漏洞
"你说主角被逐出家族，但设定里没提到收回功法。那读者会想：
功法是家族的核心资产，逐出却不收回，这不合理。家族不怕他带着功法投靠对手？"
→ 请解释或修正

❓ 合理质疑
"主角的修炼速度快得离谱，读者一定会问：同期那么多人，资源比主角好的也有，
凭什么只有主角能这么快？是金手指的原因还是天赋？"
→ 建议给个解释

🔥 好奇追问（无需回答）
"那个卖主角功法的地摊老头，到底什么来头？"

---
请逐条回应致命漏洞和合理质疑。
```

**终止条件**：致命漏洞全部清零，用户确认后进入生成宪法文件步骤。合理质疑可由用户标记"后续处理"跳过。

### 3. 生成宪法文件

按目录结构生成：

**a) `novel/constitution/core.md`**
- 读取模板 `.dsh/templates/constitution/core.md`
- 填充世界观规则，每条标记 `[不可变]` 或 `[可变]`
- 追加机器校验规则（冲突正则）
- 🔴 控制在 3000-5000 字，聚焦 [不可变] 硬规则与核心世界观
- 📖 审核红线写入 `outline.md` 头部「创作约束」段，不在此文件

**b) `novel/constitution/style.md`**
- 读取模板 `.dsh/templates/constitution/style.md`
- 填充叙事人称、时态、对话格式、语言约束
- 填充文笔约束（句式节奏、描写偏好、对话风格、情绪渲染、语言调性）—— 来自 Step 4.5 的 AI 推导结果
- 如果用户在 Step 4.5 选择了"跳过"，则文笔约束部分留空不填
- 🔴 控制在 200 字以内

**c) `novel/constitution/characters/[角色名].md`**
- 每个角色一个文件
- 🔴 **必须读取模板** `.dsh/templates/constitution/characters/_template.md`，严格按照模板格式生成
- 基于用户选择的性格模板+说话风格模板填充，融入用户的自定义调整
- 🔴 "性格内核"和"说话风格"是核心约束，必须填写
- 🔴 文件末尾必须包含 `## 演化记录` 段（初始为空，由 chapter-summarizer 每章自动追加）

**d) `novel/bookinfo.md`**
- 读取模板 `.dsh/templates/bookinfo.md`
- 填充书名、简介、类型、目标平台
- 🔴 书名 ≤ 15字，简介 150~300字
- 🔴 此文件为全书元信息，不由 SubAgent 加载，仅供作者发布时参考

### 4. 初始化风格指纹基准

如果用户提供了已有章节（模式C），执行：
```powershell
pwsh -NoProfile -File .dsh/scripts/compute-style.ps1
```

🔴 `compute-style.ps1` 默认以前10章正文建立固定风格基准；基准一旦建成，后续章节只与这套前10章母本对比，不自动漂移。

🔴 **基准体检**：脚本会同时对采样章节做段落节奏体检（均句/均段/极短段占比/超长段占比），结果写入 `state.yaml` 的 `baselineHealthy`：
- `true` → 基准可用
- `false` → 前 10 章节奏已偏离人类成书区间（如句子普遍过短），**此时锁基准会把问题固化成全书母本**。应先修正前 10 章的句子长度，再重建
- 🔴 前 30 章内允许 `pwsh -NoProfile -File .dsh/scripts/compute-style.ps1 -Rebuild` 重建一次（唯一的自愈窗口）
