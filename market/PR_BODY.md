小说模式 (Novel Mode) packages an existing long-form novel writing workflow as an installable DeepSeek Harness plugin. It adds a 小说模式 button to the conversation composer and a `/novel` slash command; either one materializes a bundled `.dsh/` working copy (novel-writing skills, subagent-role definitions, PowerShell and Python validation scripts, templates, config and rules) into the current project without overwriting files that are already there, then routes the model through the constitution, outline, design, writing, batch and validation stages (plus disassemble, import and design-export). It registers those skills as runtime skills and adds a short system-prompt routing section. The plugin ships plain JavaScript with no build step and no npm dependencies — it reaches host services only through `ctx` and `inject` — and it requires PowerShell 7 (`pwsh`) and Python 3 on the host for the workflow scripts. The code is the `packages/novel-mode-plugin/` subpackage of `github-yousen/novel` (default branch `master`).
