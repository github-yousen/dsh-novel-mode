小说模式 (Novel Mode) packages an existing long-form novel writing workflow as an installable DeepSeek Harness plugin. It adds 小说模式 (Novel Mode) as a selectable entry in the session's mode dropdown: a declarative `@deepseek-ai/dsh-agent-preset` row with a novel-writing persona and the standard tool set. The Host half registers 21 runtime skills (workflow skills, subagent roles, de-AI-writing rules) and silently materializes a bundled `.dsh/` working copy (skills, subagent-role definitions, PowerShell and Python validation scripts, templates, config and rules) into the current project when the preset is selected, without overwriting files that are already there. No custom button, slash command, tool, or prompt injection is contributed; workflow execution is skill-driven through the `/` menu. The plugin ships plain JavaScript with no build step and no npm dependencies — it reaches host services only through `ctx` and `inject` — and it requires PowerShell 7 (`pwsh`) and Python 3 on the host for the workflow scripts. Source: https://github.com/github-yousen/dsh-novel-mode (public, `main`, MIT).
